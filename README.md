# skill-creator-bot (`scb`)

**scb** is a cross-platform CLI tool for creating, validating, and publishing [Claude](https://claude.ai) skills to [ClawHub](https://clawhub.ai) and other registries.

## Features

- 🌐 **i18n**: Simplified Chinese (default) and full English UI
- 🖥️ **Cross-platform**: Linux, macOS, Windows
- 📦 **Scaffold**: Generate a complete skill project in one command
- ✅ **Validate**: Check your skill structure and SKILL.md frontmatter
- 🚀 **Publish**: Publish to ClawHub via the `clawhub` CLI
- 🔌 **Extensible**: Provider architecture for adding future registries
- 🧪 **Evals**: Manage and run skill evaluations

## Architecture

```
crates/
  scb-core       # Project model, i18n loader, templates, validation
  scb-cli        # `scb` binary with all CLI commands
  scb-registry   # RegistryProvider trait + ClawHubProvider
  scb-engine     # Engine trait + config types for eval running
  scb-tui        # Linux TUI stub (future)
locales/
  zh-CN.json     # Chinese translations (default)
  en-US.json     # English translations
```

## Build & Install

### Requirements

- [Rust toolchain](https://rustup.rs/)

```bash
git clone https://github.com/LuuuXXX/skill-creator-bot
cd skill-creator-bot
cargo build --release
# The binary is at: target/release/scb
```

To install globally:

```bash
cargo install --path crates/scb-cli
```

## Quick Start

### Create a new skill

```bash
# Chinese output (default)
scb init my-skill

# English output
scb --lang en-US init my-skill

# Specify a custom directory
scb init my-skill --dir ~/skills
```

This creates `./my-skill/` with:
- `SKILL.md` — skill definition with YAML frontmatter
- `evals/evals.json` — eval cases skeleton
- `scb.project.json` — project config (registry, engine settings)
- `scripts/`, `references/`, `assets/` — optional resource directories

### Validate a skill

```bash
scb validate --path ./my-skill
```

### Publish to ClawHub

**Prerequisites:**

```bash
# Install the ClawHub CLI
npm i -g clawhub

# Authenticate
clawhub login
```

**Publish:**

```bash
scb publish \
  --path ./my-skill \
  --registry clawhub \
  --slug my-skill \
  --name "My Skill" \
  --version 1.0.0 \
  --changelog "Initial release" \
  --tag latest
```

Publish metadata (slug, version, URL) is saved back into `scb.project.json`.

### Package a skill

> ⚠️ Full packaging is a stub in this release. It will call `scripts/package_skill.py` in a future PR.
>
> To experiment with packaging before it is fully wired up, create a script at `./my-skill/scripts/package_skill.py`.
> The expected script interface follows the same convention as `skills/skill-creator/scripts/package_skill.py` in the upstream ClawHub repository:
> it should accept no mandatory arguments, collect all required skill files, and produce a distributable archive (e.g. a `.tar.gz` or `.zip`) in the skill root.
> Refer to the upstream script as the reference implementation to ensure your bundle is compatible with the ClawHub registry.

```bash
scb package --path ./my-skill
```

### Manage evals

```bash
# List evals
scb eval list --path ./my-skill

# Run evals with the claude CLI engine
scb eval run --path ./my-skill --engine claude-cli

# Run evals with a custom engine
scb eval run --path ./my-skill --engine custom --engine-command "my-agent"

# Skip eval running
scb eval run --path ./my-skill --skip
```

## Project Config (`scb.project.json`)

Generated by `scb init`, editable by hand:

```json
{
  "skill_name": "my-skill",
  "skill_dir": "/home/user/projects/my-skill",
  "lang": "zh-CN",
  "registry": {
    "default_registry": "clawhub",
    "clawhub": {}
  },
  "engine": {
    "engine": "claude-cli",
    "args": []
  }
}
```

## Adding a New Registry

Implement the `RegistryProvider` trait in `crates/scb-registry/src/`:

```rust
pub trait RegistryProvider {
    fn name(&self) -> &str;
    fn preflight(&self) -> Result<(), PreflightError>;
    fn publish(&self, skill_path: &Path, metadata: &PublishMetadata) -> anyhow::Result<PublishResult>;
}
```

Then wire it up in `crates/scb-cli/src/cmd/publish.rs`.
